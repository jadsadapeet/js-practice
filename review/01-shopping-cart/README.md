# รีวิว 01 — ตะกร้าสินค้า

เพื่อนเขียนระบบตะกร้าสินค้ามาให้ช่วยรีวิว

**สเปกที่ต้องการ:**
- `addItem(cart, item)` เพิ่มสินค้า ถ้ามี `id` นี้อยู่แล้วให้บวก `qty` เพิ่ม ไม่ต้องเพิ่มแถวใหม่ คืนตะกร้าใหม่ ห้ามแก้ตะกร้าเดิม
- `removeItem(cart, id)` ลบสินค้าตาม id คืนตะกร้าใหม่
- `getTotal(cart)` ราคารวม (`price * qty`) ปัดทศนิยม 2 ตำแหน่ง
- `applyDiscount(total, percent)` ลดราคาตามเปอร์เซ็นต์ (0–100) ถ้า percent อยู่นอกช่วงให้ throw error
