# รีวิว 03 — บัญชีธนาคาร

class บัญชีธนาคาร โค้ดเกี่ยวกับเงินต้องรีวิวละเอียดเป็นพิเศษ

**สเปกที่ต้องการ:**
- `new Account(owner, balance = 0)` สร้างบัญชี
- `deposit(amount)` ฝากเงิน amount ต้องเป็น number ที่มากกว่า 0 ไม่งั้น throw error
- `withdraw(amount)` ถอนเงิน amount ต้องมากกว่า 0 และต้องไม่เกินยอดคงเหลือ ไม่งั้น throw error
- `transfer(to, amount)` โอนเงินให้บัญชีอื่น ถ้าโอนไม่สำเร็จ ยอดเงินของทั้งสองบัญชีต้องไม่เปลี่ยน
- `getHistory()` คืนประวัติรายการ คนภายนอกต้องแก้ประวัติจริงไม่ได้
