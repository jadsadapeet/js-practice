# 01 — พื้นฐาน

เรื่องที่ฝึก: ตัวแปร, `if/else`, loop, function, `return`

แก้ไฟล์ `exercise.js` แล้วรัน `npm run test:01`

| function | ทำอะไร | ตัวอย่าง |
|---|---|---|
| `add(a, b)` | คืนผลบวกของ a กับ b | `add(2, 3)` → `5` |
| `isEven(n)` | เป็นเลขคู่ไหม | `isEven(4)` → `true` |
| `getGrade(score)` | แปลงคะแนนเป็นเกรด: 80+ = `A`, 70–79 = `B`, 60–69 = `C`, 50–59 = `D`, ต่ำกว่า 50 = `F` ถ้าคะแนนไม่อยู่ในช่วง 0–100 ให้คืน `"invalid"` | `getGrade(75)` → `"B"` |
| `sumTo(n)` | ผลบวก 1 ถึง n ใช้ loop ถ้า n < 1 คืน `0` | `sumTo(4)` → `10` |
| `fizzBuzz(n)` | คืน array ตั้งแต่ 1 ถึง n ถ้าหาร 3 ลงตัวใช้ `"Fizz"` หาร 5 ลงตัวใช้ `"Buzz"` หารทั้งคู่ลงตัวใช้ `"FizzBuzz"` นอกนั้นใช้ตัวเลข | `fizzBuzz(5)` → `[1, 2, "Fizz", 4, "Buzz"]` |
| `max3(a, b, c)` | ค่ามากสุดใน 3 ตัว **ห้ามใช้** `Math.max` | `max3(1, 9, 4)` → `9` |

**คำใบ้:** `%` คือหารเอาเศษ เช่น `7 % 3` ได้ `1`
